**Tally:** 27 yes · 1 partial · 2 NO  → about 93% of 'proven' verdicts are about the right bug.

**The one failure mode found:** a single commit fixes several advisories (free5GC, Vikunja, Gitea 'various security fixes'). The fail→pass test belongs to one of them, and the pipeline credits it to every advisory that points at that commit.

**Fix:** when a fix commit is shared by several advisories, attribute each failing test to one advisory (test name / package vs advisory text), or downgrade to 'commit proven, advisory attribution uncertain'.
